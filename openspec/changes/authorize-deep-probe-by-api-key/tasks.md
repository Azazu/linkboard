## 2. The memory and the authorizer

- [ ] 2.1 `src/Shared/Health/ProbeMemory.php` (design decision 4: keys `probe-auth:gen:<sha256(hash)>` and `probe-auth:v:<sha256(hash)>`; `generation(hash): int` (`GET`, absent → 0); `remember(hash, int $generation, ?\DateTimeImmutable $expiresAt)` through one Lua `EVAL` that stores `{gen, exp}` with a 300-second TTL only if the current generation equals `$generation`;
